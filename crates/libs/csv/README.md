# message-csv

CSV helpers shared by converters: the attachment and participant JSON cells and CSV reading helpers.

`message-ir-format` and several exporters use this crate.

## Build and test

```bash
cargo test -p message-csv
```

Workspace setup: [CONTRIBUTING.md](../../../CONTRIBUTING.md).

## Docs

This crate is a library. CSV column list for users: https://messagecrate.app/docs/developer/reference/csv-columns/
